# WealthPulse — Personal Wealth, Cashflow & Net Worth Ledger

Comprehensive personal financial management ledger with automated income/expense categorizer, emergency fund runway calculator, monthly burn rate KPI, asset allocation breakdown, and CSV export.

## Product Highlights
- **Domain**: FinTech / Analytics
- **Visual Theme**: Mint FinTech & Emerald Jade
- **State Persistence**: Browser localStorage & FastAPI microservices
- **Zero-Dependency Web Client**: Works seamlessly on GitHub Pages

## Architecture & Quick Start
```bash
# Run Tests
pytest tests/

# Docker Deployment
docker-compose up -d --build
```
